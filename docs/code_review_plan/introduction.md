# Introduction

This document defines the formal code review plan for SpdxTool.

## Purpose

To define review-sets and the evidence required to demonstrate that each software
item has been reviewed according to the project's compliance requirements.

## Scope

This document covers all review-sets defined in `.reviewmark.yaml` for SpdxTool.

The review-sets cover source files and compliance artifacts that require formal
review, including C# source code, requirements files, design documentation, and
user guide content identified by the repository review configuration.

## Generation Source

This document collection combines checked-in review plan context with the generated
formal review plan produced by ReviewMark from `.reviewmark.yaml` and the review
evidence store.

## Audience

This document is intended for:

- Software developers working on SpdxTool
- Quality assurance personnel validating review coverage
- Project stakeholders reviewing compliance status
- Auditors verifying that files requiring review are assigned to named review-sets
